## 📌 Project Overview

Sadek Coffee Shop Management System is a complete desktop application designed to manage daily coffee shop operations through one connected system.

It includes point-of-sale operations, order and table management, menu and inventory control, customer and loyalty management, cashier register shifts, purchasing, expenses, reporting, and role-based access.

## ✨ Main Features

- POS and checkout workflow
- Orders and table management
- Menu and inventory management
- Customers and loyalty
- Register and cashier shift management
- Purchasing and expense tracking
- Reports and dashboard
- Role-based access for Admin, Manager, and Cashier
