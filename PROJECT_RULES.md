# Coffee Shop Management System

Professional desktop POS and management application.

## Development Rules
- Java desktop application using JavaFX and Maven.
- Use SQL Server as the database.
- Use a clean layered architecture.
- Separate UI, controllers, services, models, repositories/DAO, and database configuration.
- Use FXML and CSS for the JavaFX interface.
- Never hardcode database credentials in Java source files.
- Never store passwords as plain text.
- Use PreparedStatement for SQL queries.
- Validate all user input.
- Handle errors professionally and never silently ignore exceptions.
- Keep classes focused and avoid duplicated code.
- Do not modify the database schema without documenting the change.
- Do not delete or replace working functionality unnecessarily.
- Build and test after important changes.
- Fix build errors before continuing to another feature.
- Keep the UI modern, consistent, responsive, and professional.
- Security, maintainability, and data integrity are priorities.
- Use Git commits for stable milestones.
